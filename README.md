# Aplikasi Pengolahan Data Putusan

Aplikasi Java untuk mengelola data putusan dari CSV.

## Struktur data
- DynamicArray sebagai struktur data utama untuk menyimpan objek Putusan.
- Stack sebagai struktur data sekunder untuk riwayat aktivitas (audit).


## Fitur
Impor CSV, tampil data, tambah/hapus, pencarian, filter, agregasi, sorting vonis, audit, dan ekspor CSV.
